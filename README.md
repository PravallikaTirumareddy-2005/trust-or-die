# Trust or Die 🎮

Trust or Die is a decision-based web game where players must choose the correct door before time runs out.
One wrong choice and the game is over.

## 🔥 Features
- Normal and Hardcore game modes
- Time-based decision making
- Randomized hints (truth & lies)
- Persistent best score using localStorage
- Clean and responsive UI
